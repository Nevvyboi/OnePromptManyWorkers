10The whole trick10:05 · 1.5 min
ON SCREEN: The loop — reason → act → observe → done? → repeat.

This is the most important idea in the talk, so let me slow down.

The agent reasons about what to do. It acts, by calling a tool. It observes what came back. And then it asks itself one question: am I done? If yes, it stops. If no, it goes around again. Reason, act, observe, repeat.

That little circle is the entire difference between a model that talks and a system that finishes. A chatbot answers. An agent keeps going until the job is actually done.
